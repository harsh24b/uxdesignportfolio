# Harsh Bhawsar - Product & Interaction Design Portfolio

Live Portfolio website showcasing product design case studies, design systems, and creative visual journeys.

## 🚀 Live Demo
- Hosted on **GitHub Pages**: [harsh24b.github.io/Portfolio1](https://harsh24b.github.io/Portfolio1/)

## 📂 Project Structure
- `index.html` - Homepage featuring Hero, Selected Works, Work Experience, Testimonials, and About cards.
- `life-beyond-the-screen.html` - Continuous scroll-driven 3D story chapters (*Life Between the Pixels*, *Framing the Unscripted*, *Thinking With Ink & Paper*) with interactive Cover Flow galleries and lightbox previews.
- `transportation.html` - Case study page for Bus Transportation Management System.
- `style.css` - Custom styles, layout definitions, responsive breakpoints, and 3D transform perspectives.
- `Material/`, `Photography/`, `Sketches/`, `harsh photos/` - High-resolution assets and media files.

## 🛠️ GitHub Pages Deployment
This repository is configured with automated GitHub Actions deployment. Pushing changes to the `main` branch automatically triggers deployment to GitHub Pages.
