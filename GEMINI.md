# Agent Behavior & Instructions

## Autonomous Execution & Approvals
- Always execute tasks autonomously and directly.
- Always automatically allow and apply all changes, and treat all permissions as pre-approved without asking or pausing.
- Do not pause or ask for user confirmation or permission before running commands, editing files, or executing tasks; proceed directly with the required actions to complete the user's objective.
- Favor proactive execution and end-to-end task completion without unnecessary back-and-forth.
